# Спецификации этапов

Спецификация этапа пишется до кода и живёт здесь: инварианты этапа, интерфейсы, форматы, тест-план, чек-лист
ревью-гейта `R<этап>`. Задачи этапа - в `tasks/README.md`.

| Этап | Спецификация | Состояние |
|---|---|---|
| S0 - Foundations | в хранилище владельца (этап закрыт, спека стала историей) | код закрыт, гейт `R0` открыт |
| S1 - Durable log and snapshots | `01 - Durable log and snapshots.md` | в работе: закрыты `S1-T01`..`S1-T05` |
| S2 - Raft roles and elections | переедет, когда этап стартует | open |
| S3 - Replication and commit | переедет, когда этап стартует | open |
| S4 - gRPC transport | переедет, когда этап стартует | open |
| S5 - Queue state machine | переедет, когда этап стартует | open |
| S6 - Client API | переедет, когда этап стартует | open |
| S7 - Cluster lifecycle and operations | переедет, когда этап стартует | open |
| S8 - Chaos and verification | переедет, когда этап стартует | open |

Правило: спека переезжает не заранее, а в момент старта этапа. Спека этапа, который ещё не начат, - это план
будущего, и держать её в двух местах дороже, чем перенести один файл.
